# Personal Website

This is my portfolio website where I share my experience, projects, coursework, and interests outside of tech.

## How I Built It

Used **Next.js 16, React 19, and TypeScript**, with **Tailwind CSS** and custom CSS for styling.

I wanted to keep things simple, lightweight, and easy to navigate. The design uses Georgia typography, a warm ivory background, and muted-blue accents. I also added responsive navigation, persistent tab highlighting, and smooth transitions between sections.

I use **MDX** to manage content, making it easy to update my experience, projects, courses, and hobbies without changing the underlying layout.

## Running Locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000` to view the website locally.
